Hermes campus marketplace

An Android marketplace for university students.

JavaAndroid StudioFirebaseCloud storage

A campus-exclusive Android marketplace for students to buy, sell, and trade items, with real-time listings and cloud-backed image storage.

View source on GitHub ↗
Real-timelisting synchronization
Firebasedatabase and storage

The problem

General-purpose marketplaces can show items across an entire city. Hermes focuses the experience on a university community so students can find relevant listings nearby.

My contribution

Working in a team, implemented notification functionality and the data synchronization layer, supporting timely updates across the app.

The application

The app includes user authentication, product listings with image uploads, account management, push notifications, and location-based filtering for the campus community.

Technical scope

Team-based software development, event-driven updates, cloud data integration, and mobile interface implementation.
